How to use: filter tables and views below, open a card for purpose and grain, then download this page as a standalone HTML file for offline sharing. Physical relationships are in the Lucidchart ER diagram.

Schema: <catalog>.framework_meta. Pipeline-owned metrics objects (flow_events, table_load_metrics, <job>_event_log) live in the same schema but are created by pipelines, not by framework_meta.sql.

Generated for the Lakeflow framework bundle. Relationships in Lucid are logical join keys (Delta tables do not declare primary keys).
