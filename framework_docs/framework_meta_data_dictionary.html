framework_meta data dictionary

Lakeflow framework bundle · catalog schema for definitions, runs, and load metrics
Open Lucid ERD

How to use: filter tables and views below, open a card for purpose and grain, then download this page as a standalone HTML file for offline sharing. Physical relationships are in the Lucidchart ER diagram.

Schema: <catalog>.framework_meta (frozen — see META_MODEL_REVIEW.md). Per-delivery event logs (<job>_event_log) are created by pipelines. Each pipeline writes its own recon (load_ledger, ledger_detail) with an event hook; hourly framework_runs records job runs and pipeline updates, and writes the ledger row of an update whose hook was cut off.

Generated for the Lakeflow framework bundle. Relationships in Lucid are logical join keys (Delta tables do not declare primary keys).
